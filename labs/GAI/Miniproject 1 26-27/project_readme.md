# Single Image Super-Resolution (x4) Challenge — Master 2 I2A

This repository contains the baseline notebook and environment configuration for the **Master 2 (Specialty I2A) Generative AI Mini-Project** on Single Image Super-Resolution ($\times 4$ upscaling from $64 \times 64$ to $256 \times 256$).

---

## 1. Required Directory Structure

Before running the notebook locally or on Google Colab / Kaggle, place all files in the same root working directory as shown below:

```text
project_root/
│
├── baseline_super_resolution_I2A.ipynb   # Starter Jupyter Notebook
├── requirements.txt                      # Required Python packages
├── README.md                             # Project setup & execution guide
├── train_data.zip                        # Provided paired training dataset (LR & HR)
└── test_lr.zip                           # Provided 20 unseen LR test images (64x64)
```

When you execute **Section 2** of the notebook, `train_data.zip` and `test_lr.zip` are automatically extracted into the following structure:

```text
project_root/
│
├── train_data/
│   ├── LR/                               # 64x64 Low-Resolution PNG patches (0001.png ...)
│   └── HR/                               # 256x256 High-Resolution PNG patches (0001.png ...)
│
├── test_lr/
│   ├── 001.png                           # Unseen 64x64 LR test image 1
│   ├── 002.png                           # Unseen 64x64 LR test image 2
│   └── ... (up to 020.png)
│
└── submission.mat                        # Generated by Section 6 for website upload
```

## 2. Installation & Requirements

### Option A: Local Execution (Anaconda / Python Virtual Environment)
1. Create and activate a virtual environment (Python 3.9+ recommended):
   ```bash
   python -m venv sr_env
   source sr_env/bin/activate        # On Linux/macOS
   sr_env\Scripts\activate           # On Windows
   ```
2. Install the required dependencies using `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch Jupyter Notebook or JupyterLab:
   ```bash
   jupyter notebook baseline_super_resolution_I2A.ipynb
   ```

### Option B: Google Colab / Kaggle Notebooks
1. Open `baseline_super_resolution_I2A.ipynb` in Google Colab or Kaggle.
2. Enable the GPU accelerator (**Runtime $\rightarrow$ Change runtime type $\rightarrow$ T4 GPU**).
3. Upload `train_data.zip` and `test_lr.zip` to the root session folder (`/content/` on Colab or `/kaggle/working/` on Kaggle).
4. Run all cells from top to bottom. The first code cell automatically installs any missing packages.

---

## 3. Step-by-Step Execution Workflow

1. **Step 1 — Setup & Extraction (Cells 1–3):** Installs libraries, fixes random seeds, and extracts `train_data.zip` and `test_lr.zip`.
2. **Step 2 — Data Loading (Cell 4):** Loads paired `LR` ($64 \times 64$) and `HR` ($256 \times 256$) images and splits them into 90% training and 10% validation sets.
3. **Step 3 — Model Definition (Cell 5):** Defines the baseline autoencoder (`DummySRAutoencoder`). **Modify this section** to implement your improved architecture.
4. **Step 4 — Training & Loss Curve (Cell 6):** Trains the network and plots the training vs. validation loss curve.
5. **Step 5 — Local Evaluation with `sewar` (Cell 7):** Computes **PSNR**, **SSIM**, and **RMSE** on the validation split and displays visual comparisons.
6. **Step 6 — Generate `submission.mat` (Cell 8):** Runs inference on the 20 test images (`test_lr/001.png` to `020.png`), verifies that the output array has exact shape `(20, 256, 256, 3)` and type `uint8`, and exports `submission.mat`.
